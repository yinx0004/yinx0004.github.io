我在新加坡从零开始考驾照，报的是 CDC（ComfortDelGro Driving Centre）的 Class 3A，也就是自动挡小汽车。从报名到通过 BTT、拿到 PDL，一共用了 11 天。

这篇先记录到 PDL 为止，后面的实践课、FTT 和路考，考完再更新。如果你有中国驾照、打算直接转换，文末有一条容易被忽略的规定。

规定部分我都对照了新加坡警察部队（Traffic Police）的官方页面，链接放在文末。规定会调整，办理前请以官网为准。

## 先选路线：从零考还是转换

| | 从零考 | 中国驾照转换 |
|---|---|---|
| 适合谁 | 没有驾照，或者手上的驾照不符合转换条件 | 持有有效的中国驾照 |
| 要考什么 | BTT、FTT、路考 | 只需要 BTT |
| 主要麻烦 | 步骤多，每一步都要抢预约 | 材料要齐，非英文驾照要找新加坡注册的翻译公司翻译 |

外国人在新加坡居住不满 12 个月，可以直接用有效的外国驾照开车。住满 12 个月后，就需要换成新加坡驾照。

## 名词解释

| 名词 | 全称 | 说明 |
|---|---|---|
| TP | Traffic Police | 新加坡警察部队下的交通警察，负责驾照考试和发证 |
| SPF | Singapore Police Force | 新加坡警察部队，PDL 在它的 e-Services 网站申请 |
| CDC、BBDC、SSDC | ComfortDelGro Driving Centre、Bukit Batok Driving Centre、Singapore Safety Driving Centre | 新加坡的三家驾校，可以学车，也设有理论考试考点 |
| BTT | Basic Theory Test | 基础理论考试，学车的第一关；用中国驾照转换也要考 |
| FTT | Final Theory Test | 终极理论考试，考 Class 3 或 3A 要先通过它才能路考 |
| IE | Internal Evaluation | CDC 的内部模拟考，第一次学车的驾校学员要先通过它才能约 BTT |
| Induction Programme | | CDC 的入学介绍课，讲整个学车流程，不能取消或改期 |
| PDL | Provisional Driving Licence | 学习驾照，电子版，有效期 2 年，有了它才能上实践课 |
| 实践课 | Practical Lesson | 跟教练上路练车，CDC 每节 100 分钟 |
| 路考 | Practical Driving Test | 实际驾驶考试，由 TP 指派的考官主考 |
| Class 3、3A | | Class 3 是手动挡；Class 3A 是自动挡，只能开自动挡车 |
| Standard、One Team、Elite Team | | CDC 的三种班型，区别见"选哪种班" |
| PRM | Premium fee | One Team 和 Elite Team 每节实践课的附加费 |
| Stored Value | | CDC 的预付储值账户，各项费用从这里扣 |
| Booking Portal | | CDC 的网上预约系统，网页版和手机 App 都能用 |
| My Learning Journey | | CDC App 里的学车进度，显示已经完成和下一步要做的环节 |
| Slot | | 可预约的时段，视力测试、IE、BTT、实践课都要抢 |
| Singpass | | 新加坡政府的数字身份，申请 PDL 时用来登录 |
| GST | Goods and Services Tax | 新加坡的消费税，目前是 9% |

## 从零考的整体流程

1. 报名驾校
2. 视力测试（包括色盲测试）
3. Induction Programme 和 IE（Internal Evaluation，驾校内部模拟考），驾校学员才有
4. BTT（Basic Theory Test，基础理论考试）
5. 拍照，申请 PDL（Provisional Driving Licence，学习驾照）
6. 上实践课
7. FTT（Final Theory Test，终极理论考试）
8. 路考
9. 拿到驾照

Class 3 是手动挡，Class 3A 是自动挡。3A 的驾照只能开自动挡车。

## 选哪种班

CDC 的 Class 3A 在 Ubi 有三种班型，区别在于训练车和教练是否固定，每节实践课的加价也不同（含 GST）：

| 班型 | 每节实践课加价 | 训练车 | 教练 |
|---|---|---|---|
| Standard | 0 | 不固定 | 不固定 |
| One Team | 13.08 新元 | 固定 | 最多 6 位教练组成的团队 |
| Elite Team | 16.35 新元 | 固定 | 最多 4 位资深教练组成的团队 |

报名费方面，Standard 是 185.30 新元，One Team 和 Elite Team 是 201.65 新元，都包含 1 年会籍，另外收 10 新元可退押金。我报的是 Elite Team 的电动车（EV）课程，EV 课程只在 Ubi 开。

## 预约工具：CDC 网页版和 App

在 CDC 学车，预约、取消、充值、查收据都在它的网上预约系统（Booking Portal）里完成。网页版首页有十个入口，我最常用的是这三个：

- **My Bookings**：查看已经约好的课和考试。
- **Lesson Booking**：约课，比如 Induction Programme、理论课和实践课。
- **Test Bookings**：约 IE、BTT 这类考试。

其他几个也会用到：**Top-Up Store Value** 给储值账户充值，**Cancel Booking** 取消预约，**Account Statement / Receipt** 查流水和收据（下面的费用明细就是从这里整理的），**Online Learning** 是在线学习资源。

建议把 CDC 的手机 App 也装上，随时可以查看 My Learning Journey，也就是自己的学车进度到了哪一步、下一步要做什么，预约也很方便。

## 报名和视力测试

在 CDC 网上报名后，会收到一封邮件，按邮件里的方式预约视力测试。邮件可能被归到垃圾邮件，记得检查。

视力测试包括视力和色觉两部分。按照新加坡《Road Traffic (Motor Vehicles, Driving Licences) Rules》的规定，要求是：

- 在 25 米的距离，能读出黑底白字、和车牌一样大小和排列的 6 个字母与数字。平时戴眼镜的，可以戴着眼镜看。
- 在 25 米的距离，能分辨出红色、橙色和绿色。

视力测试的 slot 很紧张，要靠刷。我的观察是，每天大约早上 9 点半开放预约，晚上 6 点半左右关闭，开放期间可以不停刷新。我的做法是先约一个能约到的时间，然后继续刷，看到更早的就改期。

这里要注意的是顺序：**视力测试通过后才能约 IE，IE 通过后才能约 BTT**。每一项都要到现场，每一项都要抢 slot。前一项一过就马上去约下一项，整体节奏才不会拖长。

## Induction Programme 和 IE（内部模拟考）

**IE（Internal Evaluation）** 是 CDC 的内部模拟考，形式和 Traffic Police 的正式考试一样。第一次学车的驾校学员必须到现场通过 IE，才能预约正式的 BTT。

**Induction Programme** 是 CDC 的入学介绍，讲后面整个学车流程，我约的是 Zoom 的场次。CDC 官网写明，Induction Programme **不可以取消，也不可以改期**。

我把两项约在了同一天：先在线上参加 Induction Programme，然后去考 IE。结果 IE 开考时 Induction Programme 还没结束，我只好提前退出。最后系统还是算我完成了，算是有惊无险。不建议照着这样约，两项之间最好留出足够的时间。

## BTT 正式考试

IE 和正式 BTT 的题型一样，都是 50 道选择题，答对 45 道及格，限时 50 分钟。BTT 可以选英文、中文、马来文或淡米尔文作答，我用的是英文。

两套系统的界面风格差别很大。IE 是 CDC 自己的系统，界面明显更现代；正式 BTT 用的系统界面还很旧，像早年的 VB 程序，第一次用要花点时间适应。BTT 的系统最近在做升级，希望升级后能好用一些。

考试时一定要看清楚再点按钮。有学员做完一道题就不小心点了 End Test，考试直接结束，好不容易约到的 slot 也就作废了。

备考资料我只用了两样：

- **SPF 官方的 Basic Theory of Driving 手册**：中文版和英文版对照着看。用英文考的话，看中文版帮助理解，看英文版熟悉题目里的说法。
- **刷题 App "BTT, FTT, RTT - Theory Test SG"**：模拟题很多，适合反复练。但我发现模拟测试里有个别题目的答案是错的，遇到和手册说法不一样的，以官方手册为准。

CDC 有免费的在线理论课，用 Zoom 上，老师会讲考试重点和容易出错的题目，推荐参加。

IE 通过、约好正式 BTT 之后，我在 10 月 7 日约了实践课，最早的空位已经排到 11 月 24 日，要等 7 周左右。所以 IE 一过就可以开始约实践课，不用等 BTT 考完。

实践课的空位没有固定的开放时间。CDC 官网写明，Ubi 的各个班型都"没有固定的放课日期"，要自己经常上网查看。我约到的两节都是早上刷到的，听说空位是不定期释放的。另外，CDC 在 2024 年 7 月公布过预约上限：Ubi 的自动挡学员每月最多约 5 节实践课，手动挡 8 节。

## 拍照和申请 PDL

BTT 通过后，我直接在 CDC 拍了证件照，工作人员会把数码照片发到邮箱。拍照和考 BTT 安排在同一趟，就不用为了拍照再跑一次。

然后到新加坡警察部队的 e-Services 网站，用 Singpass 登录申请 PDL。费用是 25 新元，缴费后就通过了。PDL 是电子驾照，有效期 2 年，可以续期，驾驶教练能在线查到。没有有效的 PDL 去上实践课是违法的。

## 费用明细

到拿 PDL 为止，我实际花的钱如下（新元，含 9% GST）：

| 项目 | 费用 |
|---|---|
| CDC 报名费（Elite Team，含 1 年会籍） | 201.65 |
| 押金（可退） | 10.00 |
| 视力测试 | 1.96 |
| Induction Programme | 23.98 |
| IE（Internal Evaluation） | 7.63 |
| BTT 考试费 | 7.20 |
| BTT 行政费 | 2.94 |
| CDC 在线理论课（2 节） | 0 |
| 数码证件照 | 7.09 |
| PDL 申请费（交给 SPF） | 25.00 |
| 合计 | 287.45 |

不算报名费和押金，从视力测试到拿 PDL 一共是 75.80 新元。

后面的费用按 CDC 官网目前的价格：

- **实践课**：每节 100 分钟。工作日 8:30–10:10 和 12:45–4:15 是非高峰时段，79.57 新元；其他时段和周末是 89.38 新元。再加上班型的附加费。我约的两节都在高峰时段，Elite Team 每节是 89.38 + 16.35 = 105.73 新元。
- **FTT**：考试费 7.20 + 行政费 2.94 = 10.14 新元。
- **路考**：考试费 40.00 + 行政费 2.94 + 考试用车和热身费 317.19 = 360.13 新元。
- **会籍**：1 年到期后，续 6 个月是 65.40 新元。

CDC 的费用都从预付的储值账户里扣，要先充值才能预约。

## 我的建议

- 报名后就装上 CDC 的手机 App，随时看学车进度和预约。
- 报名 CDC 后先上它的免费在线理论课，再去考 IE 和 BTT。
- 视力测试、IE、BTT 都要到现场，而且只有前一项通过才能约下一项。每过一项就立刻约下一项。
- 约 slot 时先占一个，再继续刷更早的，有就改期。
- 考 IE 和 BTT 时看清楚按钮，别误点 End Test，否则考试直接结束，slot 作废。
- 去考 BTT 那天顺便在 CDC 拍照，省一趟。
- IE 通过后就开始约实践课，空位可能要排一个多月。空位不定期释放，没有固定时间，要经常刷，我是早上刷到的。
- 时间允许的话约非高峰时段的实践课，每节便宜将近 10 新元。
- Induction Programme 不能取消或改期，别和 IE 约得太近。

## 如果你有中国驾照

用中国驾照转换只需要通过 BTT，不用考 FTT 和路考。流程和材料网上已经有很多攻略，办理时以 Traffic Police 的[官方材料清单](https://www.police.gov.sg/-/media/Spf/Advisories/Checklist-of-Documents-for-Conversion-of-China-Driving-Licence.ashx)为准。

有一条规定很多攻略没有讲清楚：如果你的中国驾照是在**拿到第一张新加坡准证（WP、EP、学生准证等）或 PR 之后**才考的，需要额外证明在中国住满 1 年，而且实际在中国居住至少 6 个月。可以用护照出入境记录、在中国的工作证明、学历证明或纳税记录来证明。来新加坡之前就考好的驾照，不需要这项证明。

另外，非英文驾照要由新加坡注册的翻译公司出具英文翻译件，自己翻译的不收。

## 常见问题

**BTT 可以用中文考吗？**

可以，BTT 提供英文、中文、马来文和淡米尔文。

**PDL 有效期多久？**

2 年，可以在网上续期。
